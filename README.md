# 🧠 Fakkny — Smart Reminder App

> An intelligent reminder application that helps users create and manage reminders using a simple and natural experience.

🚧 **Currently Under Development**

---

## 📱 About The Project

Fakkny is a mobile reminder application currently under development.

The idea is to make creating reminders easier and more natural by allowing users to describe what they want to remember without going through complicated reminder settings.

The application is being built with Flutter and Firebase, with plans to integrate AI-powered features.

---

## 🎯 Problem

Traditional reminder applications often require users to manually enter multiple details such as:

- Task name
- Date
- Time
- Repetition
- Category

This can make creating a simple reminder more time-consuming than necessary.

---

## 💡 Solution

Fakkny aims to simplify the reminder experience by allowing users to create reminders in a more natural way.

The application is being developed to combine smart reminder management, notifications, and AI-powered features into a simple mobile experience.
